# الثيمات

كلها مبنية من لقطة الشاشة المرجعية (خلفية فاتحة، كروت بيضاء، كحلي، تمييز أزرق). الألوان تقديرية.

| الملف | الشكل | التخطيط |
|---|---|---|
| `clean-light.json` | فاتح، كرت أبيض، كحلي + أزرق | كرت الشرح فوق، الكابشن، الفيديو تحت في كرت مدوّر (R_DOWN) |
| `dark-navy.json` | غامق، تمييز أزرق | نفس التخطيط |
| `paper-grid.json` | ورقة مسطّرة بمربعات | الفيديو بنص الشاشة والشرح حواليه، وينزلق يمين/يسار حسب مكان الشرح |

ملاحظة: تخطيط `paper-grid` (الفيديو ينزلق بين الجهتين) مو جاهز في الإضافة، يتبنى ويتجرّب على أول مقطع.
الاسم واللوقو (`handle`, `logo`) فاضيين عمداً، تنحط لكل عميل.
